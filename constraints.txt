# constraints.txt — single source of truth for shared dependency versions
# across IASSIS Medical Group services.
#
# Consumers install with:
#     pip install -r requirements.txt -c <url-to-this-file>
#
# Bumping a version: edit, tag a new iassis-auth release (e.g. v0.2.0),
# then update the @v0.x.y pin in each consumer's requirements.txt.
#
# Pin policy: lock direct deps tightly, and the load-bearing transitives
# (starlette, pydantic-core, argon2-cffi) that have caused real breakage
# in the past. Leave the long tail (anyio, idna, sniffio, etc.) to pip's
# resolver — over-pinning them just creates conflicts with consumer apps.
